# Macau Casino — Baccarat & Roulette

마카오 카지노 매스 플로어를 참고한 웹 바카라·룰렛 시뮬레이터입니다. 가상 머니로만 플레이하며, PC와 모바일 모두 지원합니다.

**플레이: https://dolgorae.github.io/macau-baccarat/**

### 바카라

- 8덱 슈, 번 카드, 컷카드, 정식 서드카드 룰(Tableau)
- 免佣(노커미션) 기본: Banker 6으로 승리 시 1:0.5 · Tie 1:8 · Pair 1:11 · Super 6 1:12
- 테이블 등급별 미니멈/맥시멈 (HKD 500 ~ 10,000 테이블)
- 로드맵: 구슬판, 빅로드, 대안자, 소로, 갑유로 + 문로(問路)
- 스퀴즈(咪牌) 옵션

### 룰렛

- 싱글 제로(유러피언) 휠, La Partage 없음
- 스트레이트·스플릿·스트리트·트리오·코너·퍼스트 포·라인·더즌·컬럼·이븐머니
- 인사이드 합계/아웃사이드 미니멈, 베팅 종류별 맥시멈
- 결과 전광판(최근 결과, HOT/COLD, 레드/블랙·홀짝·하이로우 비율)

잔고와 기록은 각자 브라우저에 저장되며, 바카라와 룰렛이 같은 지갑을 씁니다. 설정에서 손익을 리셋할 수 있습니다.
